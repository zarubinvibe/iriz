# iriz 0.2.2

## English

Meeting minutes now use the supplied document template inside the app.

- DOCX: minutes first, then the full available recognition transcript on a new
  page. The matching JSON and a list of details to check are saved alongside it.
- Filling decisions and action items uses your selected CLI agent only after
  separate consent to send the transcript. Outputs remain drafts.
- Original audio and recognition text are retained before filling. Retry uses
  the saved source; older exports are not overwritten. Recent meetings survive
  an app restart.
- Speaker-model download is an explicit, verified 22 MB step. Whisper meeting
  transcription requests engine timestamps. Uncertain timing and speaker
  assignment are marked instead of invented; incomplete alignment keeps the
  entire recognition text.
- Escape stops a meeting recording without discarding its audio. Cancelling
  filling before the export commit leaves previous documents intact.
- Plain-text Codex requests no longer point to a missing JSON schema file.

The template, schema, scripts and PT Serif files travel inside the DMG.
Runtime DOCX export uses native macOS tools and does not require Python.
See [the meeting guide](https://github.com/zarubinvibe/iriz/blob/v0.2.2/docs/MEETINGS.md) for setup, privacy and limits.

Automatic recognition and generated minutes still require comparison with the
recording. This release is not notarized. Apple Silicon on macOS 14+ remains
the download target; Intel operation is not claimed as tested.

Checks include native transcription of synthetic audio through DOCX/JSON
export, template/Python-filler parity and the automated test suite. Live
microphone operation, actual provider-generated minutes, VoiceOver and visual
Word pagination were not checked for this release. Tests do not substitute
for reviewing a real meeting against its recording.

## Русский

Шаблон протокола теперь встроен в приложение и DMG. После локального
распознавания сохраняются аудио, исходный текст, DOCX, JSON и список уточнений.
В DOCX сначала идёт протокол, затем с новой страницы — вся доступная расшифровка.

Заполнение решений и поручений выбранным CLI-агентом требует отдельного
согласия на передачу текста. Результат остаётся черновиком. При отказе можно
повторить заполнение из архива без нового распознавания и без перезаписи
предыдущих документов.

Модели голосов скачиваются отдельной кнопкой: около 22 МБ, с проверкой хешей,
прогрессом и отменой. Whisper для встреч запрашивает таймкоды движка; если
привязка ненадёжна, это обозначается, а исходный текст не теряется. Escape
останавливает запись встречи, сохраняя звук. Исправлен также обычный текстовый
запрос к Codex, который раньше ссылался на отсутствующий файл схемы.

Экспорт не требует Python. [Настройка и ограничения](https://github.com/zarubinvibe/iriz/blob/v0.2.2/docs/MEETINGS.md).
Автоматический текст и протокол нужно сверить с записью. Выпуск без нотаризации;
файл предназначен для Apple Silicon и macOS 14+, работа на Intel не заявлена
как проверенная.

Проверены распознавание синтетического аудио с экспортом DOCX/JSON, совпадение
с Python-заполнителем и автоматические тесты. Живой микрофон, заполнение
реальным провайдером, VoiceOver и визуальные переносы страниц в Word для этого
выпуска не проверялись. Настоящую встречу всё равно нужно сверить с записью.

## 简体中文

会议模板现已包含在应用和 DMG 中。本地识别后保存录音、原始文本、DOCX、JSON
和待核实事项。DOCX 先放纪要，再另起一页放完整的可用转写。

通过所选 CLI 代理填写决策和任务前，会单独征求发送文本的同意。结果仍是草稿。
失败后可以从存档重试，不必重新识别录音，也不会覆盖旧文档。

说话人模型通过独立按钮下载，约 22 MB，包含哈希校验、进度和取消操作。
Whisper 会议识别会请求引擎时间戳；无法可靠对齐时会明确标注，并保留全部原文。
Escape 停止会议录音但不丢弃音频。普通 Codex 文本请求也已修复，不再指向不存在的
JSON 模式文件。

导出不需要 Python。详见[设置与限制](https://github.com/zarubinvibe/iriz/blob/v0.2.2/docs/MEETINGS.md)。自动识别文本和纪要仍需与
录音核对。本版本尚未通过 Apple 公证；下载面向 Apple Silicon 和 macOS 14+，
不宣称已验证 Intel 运行。

已检查合成音频的本地识别至 DOCX/JSON 导出、与 Python 填充脚本的一致性及自动化
测试。本版本未检查真实麦克风、实际提供商生成的纪要、VoiceOver 和 Word 可视分页。
这些测试不能代替将真实会议纪要与录音逐项核对。
