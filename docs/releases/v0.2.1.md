# iriz 0.2.1

## English

Apple Silicon · macOS 14+ · self-signed, not notarized by Apple.

- Onboarding offers **Download and install Parakeet** (about 500 MB), progress and retry before the permission steps. Recover a skipped or missing model through **Settings → Dictation → Download Parakeet model…**. Parakeet is the only model with automatic installation; it does not recognize Chinese speech.
- Packaged apps include their language resources and Whisper framework. English and Chinese translations resolve from the app bundle, without the developer's build directory.
- Fixes cover the dictation overlay, history search and deletion, file transcription, meeting saves and settings navigation.
- The README now has a direct macOS download button. The release includes SHA-256 checksums and a build manifest.

Open the DMG, drag iriz into Applications, then follow [the first-launch guide](https://github.com/zarubinvibe/iriz/blob/main/docs/DOWNLOAD.md). The model is not included in the image. Intel is not supported by this download. Updates remain manual; quit iriz before replacing the app. Models and history stay outside the app bundle.

## Русский

Apple Silicon · macOS 14+ · самоподпись, без нотаризации Apple.

- В знакомстве перед разрешениями есть кнопка **«Скачать и установить Parakeet»** (около 500 МБ), прогресс и повтор после ошибки. Пропущенную или удалённую модель можно восстановить через **«Настройки → Диктовка → Скачать модель Parakeet…»**. Автоматическая установка есть только для Parakeet; китайскую речь он не распознаёт.
- В пакет приложения входят переводы и Whisper. Английский и китайский загружаются из приложения без каталога сборки разработчика.
- Исправлены плашка диктовки, поиск и удаление истории, расшифровка файлов, сохранение встреч и переходы в настройках.
- В начале README появилась кнопка скачивания для macOS. К выпуску приложены суммы SHA-256 и манифест сборки.

Открой DMG, перетащи iriz в Applications и пройди [первый запуск](https://github.com/zarubinvibe/iriz/blob/main/docs/DOWNLOAD.ru.md). Модели внутри образа нет. Этот файл не предназначен для Intel. Обновление ручное: закрой iriz перед заменой приложения. Модели и история хранятся отдельно.
