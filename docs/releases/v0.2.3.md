# iriz 0.2.3

![iriz dictation settings with local recognition controls and the speech model selector](../assets/shots/page-dictation.png)

## English

Dictation no longer immediately stops with a red cross just because another program keeps Secure Keyboard Entry active. If macOS Accessibility confirms that the current field or window is ordinary, iriz can start recording there.

Password fields, secure content and anything iriz cannot verify still fail closed. The same protection applies before pasting text and before a delayed Enter key. Audio capture and the speech-recognition core did not change in this release.

The meeting export introduced in 0.2.2 remains in the app and DMG: minutes, the full available transcript on a separate page, matching JSON and the built-in document template.

The download is for Apple Silicon on macOS 14 or newer. The Parakeet model is separate and is about 500 MB. The app uses ad hoc signing and is not notarized by Apple. We do not claim to have tested Intel Macs or first launch from a clean macOS account.

## Русский

Диктовка больше не обрывается сразу с красным крестиком лишь потому, что другая программа держит включённым Secure Keyboard Entry. Если Accessibility в macOS подтверждает, что текущее поле или окно обычное, iriz начинает запись.

Парольные поля, защищённое содержимое и всё, что iriz не смог проверить, по-прежнему блокируются. Та же защита действует перед вставкой текста и отложенным Enter. Захват звука и движок распознавания речи в этом выпуске не менялись.

Экспорт встреч из 0.2.2 остаётся внутри приложения и DMG: протокол, вся доступная расшифровка на отдельной странице, соответствующий JSON и встроенный шаблон документа.

Файл предназначен для Mac с Apple Silicon и macOS 14 или новее. Модель Parakeet скачивается отдельно и занимает около 500 МБ. Приложение подписано ad hoc и не прошло нотаризацию Apple. Работа на Intel и первый запуск в чистой учётной записи macOS не заявлены как проверенные.

## 简体中文

现在，即使其他程序仍启用了 Secure Keyboard Entry，听写也不会因此立刻以红叉结束。只要 macOS 的 Accessibility 确认当前输入框或窗口不是受保护内容，iriz 就可以开始录音。

密码输入框、安全内容，以及 iriz 无法确认的状态仍会按 fail-closed 原则阻止操作。粘贴文本和延迟发送 Enter 之前也会执行同样的保护。本版本没有修改音频采集或语音识别核心。

0.2.2 加入的会议导出仍包含在应用和 DMG 中：会议纪要、另起一页的全部可用转写文本、对应的 JSON，以及内置文档模板。

此下载适用于 macOS 14 或更高版本的 Apple Silicon Mac。Parakeet 模型需要另外下载，大小约为 500 MB。应用使用 ad hoc 签名，尚未通过 Apple 公证。我们尚未验证 Intel Mac 或全新 macOS 账户的首次启动。
