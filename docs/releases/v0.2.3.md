# iriz 0.2.3 — кандидат выпуска

Исправление ложного отказа запуска записи. Выпуск ещё не опубликован.

- Фоновый защищённый ввод клавиатуры больше не запрещает запись, когда
  метаданные текущего элемента подтверждают обычное поле или окно.
- Настоящее парольное поле и защищённое содержимое проверяются отдельно,
  в том числе перед вставкой текста и отложенным Enter.
- Обучение не читает значение защищённого или недоступного элемента.
- Если текущий элемент недоступен для проверки, активная системная защита
  по-прежнему запрещает запуск и автоматическую вставку.

Системная защита macOS и защита автоматического исправления клавиатуры
не отключаются. Движок распознавания и захват звука не заменены. В установленной
сборке 0.2.3 пройдено несколько живых циклов «микрофон → распознавание → вставка».
Опубликованный DMG 0.2.2 не перезаписывается.
