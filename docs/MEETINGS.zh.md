1. 打开**设置 → 会议**，使用页面上的控件安装语音模型。
2. 把俄语会议录音加入队列。

也可以从菜单栏开始实时录音。会议音频会被保留，普通听写则不会保留音频。

处理前，请选择仅在本地转写，或明确同意把转写文本发送给所选的 CLI 智能体。确认对话框会显示发送目标和模型。这项授权与听写文本润色的授权相互独立。如果尚未配置 CLI，请将它设为**提示词模式**。服务商可能收取费用或限制访问。发送给智能体的请求不包含音频文件。

## 保存的内容

会议归档包含音频副本、Markdown 格式的原始识别文本，以及由 iriz 写入一次、后续导出不会覆盖的 `meeting-source.json`。每次导出都会新建一个版本目录，其中包含四个文件：

- `meeting-minutes.docx`：第一部分为会议纪要；第二部分从新的一页开始，收录当前可用的完整转写；
- `meeting-data.json`：生成该 DOCX 时实际使用的全部字段和重复区块；
- `clarifications.txt`：仍不明确的信息和仍需核实的事项；
- `export.json`：导出时间，以及会议纪要是否已填写。

系统会校验全部 38 个常用字段和 7 类区块。每张实际生成的卡片都必须包含必填键。缺失信息会被明确标注；空列表不会凭空生成参会者、决定或任务。系统要求智能体区分提议和已经达成的决定；请对照录音核实这一区别。文档不会被自动批准。

仅在本地处理时，系统会生成转写文本和未填写的纪要表单。之后可选择**填写纪要**，再通过智能体补全内容。如果智能体或导出器失败，已保存的原始资料仍会保留。重试会直接读取该资料，不会重新识别音频，也不会覆盖旧版本的导出。应用重启后，最近的会议仍然可用。旧版归档如果没有原始资料快照，必须重新导入，才能使用新版导出功能。

## 准确性与限制

转写文本会原样保留语音引擎返回的内容，包括重复和未说完的句子。但自动识别结果并不等同于经过人工核对的逐字稿。依赖姓名、日期、决定或任务分配前，请先与录音核对。

只有语音引擎提供的有效时间信息才会被写成时间戳。无法确定的时间、说话人和未完整对齐的内容都会被明确标注。对齐失败时，系统会保留全部识别文本，不会丢弃末尾内容或编造时间戳。说话人标签只代表检测到的不同声音，并不代表已经确认了具体身份。导入日期不会被当作会议日期；文件完整也不能证明整场会议都被录下。

智能体请求目前最多接收 120,000 字节的 UTF-8 识别文本。更大的原始资料仍会保存，但不会发送，也不会在没有提示的情况下截断。智能体的响应必须通过结构和原始证据校验；响应无效时，最多只会再发起一次修复请求。拒绝、超时或取消都不会触发未告知用户的服务商切换。

## 说话人模型

“会议”页面有一个单独的**下载说话人模型 · 22 MB**按钮。这项可选下载包含 21 个锁定版本的文件，总大小为 21,599,417 字节。页面会显示下载进度，并支持取消和重试。应用重启后会重新检查已安装的文件；识别过程不会在后台静默下载这些模型。没有这些模型时，转写仍可正常工作，但无法确定说话人。

所用模型是 [FluidInference 的 Speaker Diarization CoreML](https://huggingface.co/FluidInference/speaker-diarization-coreml/blob/1ed7a662fdc7109e36d822db793ee6eebdaf8594/README.md)，版本 `1ed7a662fdc7109e36d822db793ee6eebdaf8594`。模型卡声明采用 CC BY 4.0，并注明上游模型为 [Pyannote Community-1](https://huggingface.co/pyannote/speaker-diarization-community-1)。模型许可证与 FluidAudio SDK 许可证互不相同。应用会原样下载锁定版本的模型文件，并在写入缓存前校验文件大小和 SHA-256 哈希。这些权重不会打包进应用或 DMG。下载模型不会为语音识别器开启联网功能，也不会上传音频或转写文本。

## 模板与隐私

应用已内置模板、数据结构和字体。导出不依赖桌面文件夹、Python、在线下载或源码仓库。原生填充器已与软件包中的 Python 填充器做过对照测试。原始模板不会被修改。输出会保留 PT Serif、页面设置、标题和页脚页码，并删除供文档编写者使用的说明。如果阅读文档的环境没有安装 PT Serif，阅读器可能会替换字体；应用已随附字体文件和 OFL 许可证。

应用不会加密会议归档和导出文件，文件权限仅限当前用户访问。启用 FileVault 后，可由它提供磁盘加密。只有在单独确认授权后，外部智能体才能看到转写文本。自定义 CLI 配置可能改变数据实际发送到的端点。通过命令行参数传递提示词的 CLI 还会让同一账户下运行的进程看到提示词；授权对话框会提醒这一点。

普通的 `iriz transcribe` 命令仍然只负责把文件转写为文本；本文所述的会议工作流只能在应用内使用。
