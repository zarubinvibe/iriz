# 首次安装时的对话

你好。我是 Fil，一名会写代码的律师，iriz 是我做的。

接下来由代理带你走。它会在动手之前先说明要做什么，并说清每一步的代价：磁盘上会多出什么、时间花
在哪里、哪里由你选择。如果哪一步不合适，直接在对话里说，可以跳过。

这件事从头到尾只为一个承诺：你说话的声音不会离开这台机器。唯一一次联网是下载识别模型，而且由你
按下按钮才开始。

<!-- owner-greeting:end -->

## 第 1 步：先看看你在什么机器上运行

**我在做什么：** 检查 macOS 版本、处理器，以及有没有装带 Swift 6 的 Xcode。

**为什么：** iriz 需要 macOS 14 或更新。玻璃浮窗和真正的 Liquid Glass 属于 macOS 26；在 14 和
15 上应用能用，但浮窗是按旧方式绘制的。这件事现在知道，比构建完再知道好。

**磁盘上会改变什么：** 什么都不改。这一步只是读取。

**你会得到：** 一个答案——能不能继续，以及你会落在哪条视觉分支上。

**岔路：** 没有 Xcode 也没关系。从 Releases 页面下载现成的磁盘映像，构建那几步就跳过。

## 第 2 步：把源码拿下来

**我在做什么：** 把仓库克隆到你指定的文件夹，或者解压 ZIP。

**为什么：** 之后所有事情都在那个文件夹里进行，它应该放在你以后找得到的地方。

**磁盘上会改变什么：** 多出一个文件夹，约 40 MB。其他地方什么都不写。

**你会得到：** 一棵项目树，里面能看到 `Sources`、`Tests`、`scripts` 和 `docs`。

## 第 3 步：构建应用

**我在做什么：** 先运行 `bash install.sh`，和你一起读它的报告，然后才运行
`bash install.sh --build`。

**为什么：** 不带参数时安装脚本什么都不装。它会讲清这是什么程序、看看你机器上缺什么，并对项目树
做一次自检。这是你在任何事情发生之前叫停的机会。

**磁盘上会改变什么：** 第一条命令什么都不改。第二条会拉取 Swift 依赖（`.build` 里约 300 MB），
并把构建好的应用放进 `/Applications`。

**你会得到：** 屏幕右上角菜单栏里的图标，以及欢迎窗口。

**岔路：** 如果你不想动 `/Applications`，说一声，我们就构建到项目文件夹里，从那里运行。

## 第 4 步：授予权限并下载模型

**我在做什么：** 带你过三项 macOS 权限——麦克风、辅助功能、输入监控——然后开始下载识别模型。

**为什么：** 没有麦克风就没有可听的；没有辅助功能，文字没地方粘贴；没有输入监控，按键根本听不
到。模型就是那半个 GB，应用一生只为它联网一次。

**磁盘上会改变什么：** 模型放到 `~/Library/Application Support/iriz/Models`。权限写进 macOS
的系统数据库，不写进应用。

**你会得到：** 可以用的口述。按键，说一句话，再按一下——文字就落在光标闪烁的地方。

## 第 5 步：验证这一切是不是诚实的

**我在做什么：** 运行项目的闸门，并把它们的完整输出给你看。

**为什么：** “声音不会离开这台机器”这个承诺，要由工具来验证，而不是 README 里的一段话。闸门会
在构建出的二进制里踢一遍网络相关符号，并向内核询问运行中的应用有没有打开任何一个套接字。

**磁盘上会改变什么：** 什么都不改。闸门只读取和统计。

**你会得到：** 一份你亲眼看过的绿色报告，而不是听人保证。

```bash
bash scripts/verify.sh && bash scripts/offline_binary_gate.sh
```
