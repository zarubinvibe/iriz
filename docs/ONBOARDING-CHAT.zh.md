# 首次安装时的对话

你好。我是 Fil，一名会写代码的律师，iriz 是我做的。

接下来由代理带你走。它会在动手之前先说明要做什么，并说清每一步的代价：磁盘上会多出什么、时间花
在哪里、哪里由你选择。如果哪一步不合适，直接在对话里说，可以跳过。

这件事从头到尾只为一个承诺：你说话的声音不会离开这台机器。识别模型需要联网下载，由你按下按钮
才开始。

<!-- owner-greeting:end -->

## 第 1 步：先看看你在什么机器上运行

**我在做什么：** 检查 macOS 版本、处理器，以及有没有装带 Swift 6 的 Xcode。

**为什么：** iriz 需要 macOS 14 或更新。玻璃浮窗和真正的 Liquid Glass 属于 macOS 26；在 14 和
15 上应用能用，但浮窗是按旧方式绘制的。这件事现在知道，比构建完再知道好。

**磁盘上会改变什么：** 什么都不改。这一步只是读取。

**你会得到：** 一个答案——能不能继续，以及你会落在哪条视觉分支上。

**岔路：** 没有 Xcode 也没关系。从 Releases 页面下载现成的磁盘映像，构建那几步就跳过。

## 第 2 步：把源码拿下来

**我在做什么：** 把仓库克隆到你指定的文件夹，或者解压 ZIP。

**为什么：** 之后所有事情都在那个文件夹里进行，它应该放在你以后找得到的地方。

**磁盘上会改变什么：** 多出一个文件夹，约 40 MB。其他地方什么都不写。

**你会得到：** 一棵项目树，里面能看到 `Sources`、`Tests`、`scripts` 和 `docs`。

## 第 3 步：构建应用

**我在做什么：** 先运行 `bash install.sh`，和你一起读它的报告，然后才运行
`bash install.sh --build`。

**为什么：** 不带参数时安装脚本什么都不装。它会讲清这是什么程序、看看你机器上缺什么，并对项目树
做一次自检。这是你在任何事情发生之前叫停的机会。

**磁盘上会改变什么：** 第一条命令什么都不改。第二条会拉取 Swift 依赖（`.build` 里约 300 MB），
并把构建好的应用放进 `/Applications`。

**你会得到：** 屏幕右上角菜单栏里的图标，以及欢迎窗口。

**岔路：** 如果你不想动 `/Applications`，说一声，我们就构建到项目文件夹里，从那里运行。

## 第 4 步：下载模型并授予权限

**我在做什么：** 带你进入欢迎窗口的第二步，就在问候之后。点击“下载并安装 Parakeet”，iriz 会下载
约 500 MB 的文件，安装模型并将它选为识别引擎。窗口会显示进度，下载时间取决于网络速度。下载期间
可以点“下一步”，继续授予 macOS 权限。

**为什么：** 没有模型就无法听写。麦克风让 iriz 听到你说话，辅助功能用于粘贴文字，输入监控用于
响应快捷键。安装完成后，语音识别在你的 Mac 上运行，不需要联网。

**磁盘上会改变什么：** 模型放到
`~/Library/Application Support/FluidAudio/Models/parakeet-tdt-0.6b-v3`。
你不用手动移动文件。权限写进 macOS 的系统数据库，不写进应用。

**岔路：** “稍后下载”会跳过下载。之后可以从设置 → 口述 →“下载 Parakeet 模型…”返回安装页面。
如果模型还没装好，试用步骤也有“前往安装模型”按钮。下载失败时，先看窗口里的原因，处理后再点
“重试”。模型装好后，我们再尝试听写。

**你会得到：** 模型装好、权限授予后，我们在欢迎窗口里测试听写。按键，说一句话，再按一下，文字
会出现在试用输入框中。

## 第 5 步：验证这一切是不是诚实的

**我在做什么：** 模型下载完成后，运行测试和项目闸门，给你看输出，并指出跳过了哪些检查。

**为什么：** 网络闸门把构建出的二进制中的网络符号与基准比较。如果应用从 `/Applications` 运行，
还会查看它在检查那一刻打开的套接字；应用没运行时会跳过这项检查。一次快照不能证明应用从未联网，
而下载模型时出现网络连接是正常的。

**磁盘上会改变什么：** 测试会更新 `.build` 并写入日志，闸门还会清理自己的临时测试文件。

**你会得到：** 一份实际检查结果的报告。失败和跳过的检查都会写明，不会被改成“一切正常”的保证。

```bash
bash scripts/verify.sh && bash scripts/offline_binary_gate.sh
```
