# 开始使用

[English](ONBOARDING.md) · [Русский](ONBOARDING.ru.md) · [README](../README.zh.md)

如何阅读：首次安装请先打开安装指南；已安装的用户可从需要的章节继续。

状态：已更新；当前公开构建仅支持 Apple Silicon。

这就是将来出现在菜单栏里的图标。普通听写时，语音在这台 Mac 上转成文字，音频不会离开本机。只有你明确同意并启用可选的 agent 模式后，应用才可能把已经转写的文字发给外部 agent。
这份引导写给第一次安装 iriz 的人。每一步都说明该点什么或输入什么，也告诉你接下来应该看到什么。如果屏幕上的结果不同，就停在那一步。答案在这个差别里，不在页面下面。

你需要一台运行 macOS 14 或更新版本的 Apple Silicon Mac。安装 Parakeet 约需 500 MB，还要给临时下载文件留出空间。这是唯一可以一键安装的模型。此版本不支持 Intel。若从源码构建，需要已验证的 Xcode 26.6（macOS 26 SDK、Swift 6.3.3）；安装现成 DMG 不需要 Xcode 或终端。

下载应用、完成首次启动、恢复模型和手动更新的方法都在[安装指南](DOWNLOAD.zh.md)里。下面介绍应用的其余界面。

## 安装

1. **先确认系统版本。** 点屏幕左上角的 Apple 菜单，再点「关于本机」。

   你会看到 Mac 名称和系统版本。需要 macOS 14 或更新版本。低于 14 就先停下：应用无法在这个系统上启动。

2. **下载磁盘映像。** 获取 [Apple Silicon 版 DMG](https://github.com/zarubinvibe/iriz/releases/latest/download/iriz-macos-arm64.dmg)。发布页也会列出带版本号的 `iriz-<版本>-arm64.dmg`。此版本不支持 Intel，也不包含 universal 映像。

   「下载」文件夹里会出现一个十几 MB 的文件。这是正常的。语音模型不放在 DMG 里；到第 7 步，应用才会按你的操作下载并安装模型。

3. **把图标拖进 Applications。** 双击刚下载的 `.dmg`。

   窗口里只有两个项目和一支箭头：应用图标与 `Applications` 文件夹。把应用图标拖到文件夹上。完成后关闭窗口，并在 Finder 侧边栏推出磁盘映像。

4. **也可以自己构建，替代第 2、3 步。** 打开终端：

   ```bash
   git clone https://github.com/zarubinvibe/iriz.git ~/iriz
   cd ~/iriz
   bash install.sh
   ```

   不带参数时，安装器不会安装任何东西。它会介绍应用，检查这台 Mac 缺什么，运行源码树自检 `scripts/selfcheck.sh`，再给出下一步。你会看到一份清单：哪些已就绪，哪些还缺。若想亲自验证网络边界，可对通过 `install.sh` 构建的应用运行 `scripts/offline_binary_gate.sh`。清单无误后再构建：

   ```bash
   bash install.sh --build
   ```

   首次构建会下载依赖，所以之后会更快。完成后，应用位于 `/Applications`，图标出现在菜单栏。你也可以下载源码 [ZIP](https://github.com/zarubinvibe/iriz/archive/refs/heads/main.zip)，解压后在文件夹里运行相同命令；安装器仍然需要 git。

5. **第一次打开应用。** 此版本使用 ad hoc 签名，没有 Developer ID 证书，也未通过 Apple 公证，因此 macOS 无法确认发布者。

   如果 macOS 提示无法验证发布者或无法检查应用，只在你信任此仓库并核对过下载文件时继续。先尝试从 Applications 打开 iriz，再前往 **系统设置 → 隐私与安全性 → 仍要打开**。参见 [Apple 的说明](https://support.apple.com/en-us/102445)。

   如果 macOS 提示应用已损坏，请停下并从官方发布页重新下载。不要绕过恶意软件警告，也不要关闭 Gatekeeper。警告仍在时，请停止启动并报告问题。

   如果你在第 4 步自己构建，这一步与你无关：本机构建不会带有下载隔离标记。

   你会看到：屏幕右上角、时钟旁出现菜单栏图标，同时打开**「认识 iriz」**窗口。

## 首次启动

6. **先看第一屏。** 窗口底部的**「下一步」**会带你去安装模型。

   第一屏只说明基本用法：按一次键，说一句话，再按一次；文字会出现在光标闪烁的位置。

7. **用最短路径安装模型。** 在**「安装语音识别模型」**页面点**「下载并安装 Parakeet」**。应用会下载、安装并选择 Parakeet。

   下载约 500 MB，速度取决于网络，进度会显示在页面上。下载期间可以继续授予权限，但首次听写前要等到**「模型已就位」**。如果失败，点**「重试」**。

   跳过了模型，或需要重新下载？打开 **iriz → 设置 → 口述 → 下载 Parakeet 模型…**。模型已经安装时，按钮会显示为**「设置语音识别…」**。只有 Parakeet 可以自动安装，而且它不识别中文语音。作者本人使用手动安装的 Whisper large-v3-turbo。你可以在[模型指南](MODELS.zh.md)里比较当前支持的配置和其他下载候选。界面语言与语音语言是两项独立设置。

   下一屏会说明 iriz 住在哪里。它没有主窗口，也不出现在程序坞中。历史、词典和设置都从菜单栏图标打开。看完后继续处理权限。

8. **允许使用麦克风。** 在**「需要麦克风」**页面点**「允许使用麦克风」**。

   macOS 会弹出系统询问，点允许。回到引导窗口，权限状态会从「尚未授权」变成**「已授权」**。没有麦克风权限时，键盘布局纠正仍然可用，但听写不可用。

9. **授予辅助功能权限。** 在**「需要插入文字的权限」**页面点**「打开系统设置」**。

   系统设置会打开「辅助功能」列表。找到 `iriz`，手动打开开关；macOS 不允许应用替你完成这一步。回到引导窗口后，状态会显示**「已授权」**。这个权限用于把文字插入邮件、聊天或其他输入框。

10. **授予输入监控权限。** 在**「还差按键权限」**页面再次点**「打开系统设置」**。这次打开的是「输入监控」。找到 `iriz`，打开同一个开关。

    开关打开后，应用会立刻自动重启。这是 macOS 的要求，不是故障。引导窗口会回到刚才的位置。没有这个权限，应用看不到听写快捷键，也无法发现用错键盘布局输入的词。

## 测试

11. **先在引导窗口里听写一句。** 等模型就绪。在**「现在就试试」**页面，按一下右 ⌘（空格键右侧的 Command），说一句话，再按一下。

    使用 Parakeet 时，可以说一段俄语，例如：`Привет, это проверка. Слышишь меня хорошо?`（你好，这是测试。能听清吗？）。说话时会看到「在听，说吧」。第二次按键后会出现「正在整理你说的话」，随后文字进入窗口里的输入框。引导窗口开着时，文字只写到这里。快捷键被其他应用占用时，可点**「按键被占用？换一个」**。

12. **后面两屏可以跳过。** 它们介绍**「说的话可以变成任务」**和**「说俄语，得到英语」**。

    从这里开始，就不再是“所有处理都在你的 Mac 上完成”。单独的快捷键会把转写文本交给你亲自安装并登录的外部 agent CLI，由它把零散的话整理成任务。翻译也通过同一个 agent 完成：说俄语，插入英语。因此，这些模式默认关闭，只有你同意并亲自启用后才会发送转写文本。可以放心点**「暂时跳过」**：普通听写和键盘布局纠正不依赖 agent，之后也能在设置里回来开启。

13. **关闭引导，再向真实输入框听写。** 点**「完成」**。打开备忘录或任何可以输入文字的应用，点一下输入框，让光标闪烁。

    按右 ⌘，说一句话，再按右 ⌘。文字会出现在光标处；邮件、聊天和终端里也是一样。再检查键盘布局纠正：输入 `ghbdtn`，看看它是否自动变成俄语的 `привет`。

### 如果文字没有出现

14. **文字没有插进去时，先别重说。** 它没有丢，引导最后一屏也会说明这一点。

    - 听写浮窗会展开，显示完整转写。可以直接从那里复制。
    - 右 ⌘ + ⇧ 打开历史窗口：⏎ 粘贴，⌘C 拷贝，Esc 关闭。所有听写记录都在那里。
    - 完全没有反应，图标也不动：点菜单栏图标。应用会直接告诉你缺少哪项权限。最常见的是「输入监控」。
    - 同一个词总是识别错误：点开菜单栏中的 iriz 图标 → **「设置…」** → **「替换词典」**，填入替换规则。磁盘上的原始转写不会改变；规则只修改最终插入输入框的文字。

## 以后如何更新

如果你安装的是 DMG，请按[手动更新与回退指南](DOWNLOAD.zh.md#更新与回退)操作：替换应用前先退出 iriz，并保留旧应用或磁盘映像，直到确认新版正常。

如果你从源码构建，请在 Claude Code 中打开项目并运行 `/iriz-update`。它会先说明将要发生的变化，只做快进更新，不改动你的设置、词典和听写记录。

## 如果这份引导有帮助

如果 iriz 哪怕只替你完成过一次不把音频交给第三方云端的听写，请给它一个星标：[https://github.com/zarubinvibe/iriz](https://github.com/zarubinvibe/iriz)。只需一秒，却会影响其他人能否找到这个项目。

你已经走完全部流程，也最容易发现哪里不顺。改进路径很短：fork 仓库，新建分支，提交 commit，push 后打开 Pull Request。不要直接推送到 `main`；发布门禁会拒绝这种推送。

如果某一步坏了，或文档说错了，请在 [GitHub Issues](https://github.com/zarubinvibe/iriz/issues) 里写清楚你做了什么、屏幕显示了什么。文档错误和代码缺陷一样，都值得修复。

## 界面长什么样

下面每张界面图都由工具从正在运行的应用中截取：`iriz --capture-docs`。不是效果图，而是你会看到的真实窗口。

### 浮窗

<p align="center"><img src="assets/shots/plate-resting-dark.png" alt="屏幕底部一枚小小的玻璃水滴，里面有一条细绿线，边缘泛着柔和的光晕" width="45%"></p>

不说话时，它就是这样。水滴浮在其他窗口之上，不做任何操作。

<p align="center"><img src="assets/shots/plate-listening-dark.png" alt="录音中的浮窗：一枚宽宽的胶囊，绿色声波在玻璃里流动" width="70%"></p>

说话时，它会变成这样。玻璃里的声波直接告诉你：应用有没有听见声音。

<p align="center"><img src="assets/shots/plate-hover-dark.png" alt="浮窗展开成一排六个圆形按钮：麦克风、提示词、翻译、RU、历史、设置" width="100%"></p>

把鼠标移上去，水滴会展开成一排按钮：录音、提示词、翻译、语言、历史、设置。浮窗可以拖动，并会吸附到屏幕边缘十二个位置之一。

<p align="center"><img src="assets/shots/plate-open-text-dark.png" alt="展开的浮窗面板：实心卡片上显示文字，下方有复制按钮、关闭叉号和一排按钮" width="100%"></p>

点一下会展开文字面板。可以用三种方式关闭：点叉号、按 Escape，或点按钮以外的位置。
