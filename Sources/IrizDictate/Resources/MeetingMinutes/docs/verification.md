# Проверка переносимого комплекта

Дата: 13.09.2026.

- template.docx совпадает байт-в-байт с исправленным владельцем файлом; 87 полей сохранены.
- Текстовая копия и fields.json соответствуют текущему DOCX; удаленные владельцем общий заголовок и вступление не восстановлены.
- Выполнены 8 тестов заполнителя: повторяемые карточки, сохранение остальных частей DOCX, переносы строк, разделенный между runs плейсхолдер, сохранение оформления соседних runs, фигурные скобки в исходном тексте, объявления пространств имен, отклонение неизвестных ключей/измененной структуры, защита от перезаписи.
- Пакет скопирован в другую папку с пробелами. Заполнитель запущен из внешней рабочей папки через Python с ключом -S, без доступа к сторонним Python-пакетам. Учебный результат содержит двух участников и две реплики.
- Все части учебного DOCX, кроме word/document.xml, совпадают с эталоном по байтам. Учебный текст и переносы проверены в XML.
- Шрифты PT Serif включены вместе с лицензией. Сборщик не устанавливает их в систему автоматически.

Эти проверки подтверждают переносимость и целостность структуры, а не полноту реальной аудиозаписи или правильность содержания протокола. Полная пагинация учебного результата в Word/LibreOffice не проверялась. Эталон сохраняет пользовательскую верстку без пересборки.

Повторный запуск: `python3 -m unittest discover -s tests -v`. Контрольные суммы комплекта: `python3 scripts/verify_package.py`.
