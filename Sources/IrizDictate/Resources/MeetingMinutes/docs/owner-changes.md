# Изменения владельца и происхождение формы

Подготовлено 13.09.2026. Основной файл template.docx скопирован без пересборки и без изменения байтов из исправленной владельцем версии.

Владелец удалил общий заголовок «ПРОТОКОЛ И ПОЛНАЯ РАСШИФРОВКА ВСТРЕЧИ» и вводный абзац о шаблоне. Документ начинается сразу с «ЧАСТЬ I. ПРОТОКОЛ ВСТРЕЧИ». Все 87 полей сохранены. Не возвращать удаленные элементы при следующем заполнении.

DOCX — эталон оформления. template.md — его текстовое представление, без верстки Word. При расхождении ориентироваться на последнюю согласованную правку DOCX.
