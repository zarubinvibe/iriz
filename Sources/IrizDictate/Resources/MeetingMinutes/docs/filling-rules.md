# Правила заполнения

## Основной порядок

1. Прочитайте материалы, установите дату и цель встречи, перечислите доступные записи и заметки.
2. Подготовьте полную расшифровку доступной записи, обозначьте говорящих, таймкоды и пробелы.
3. По материалам и расшифровке составьте протокол: обсуждение, явно принятые решения, поручения и открытые вопросы.
4. В итоговом документе расположите протокол первым, затем полную расшифровку с новой страницы. Расшифровку не заменяйте ссылкой или резюме.

## Достоверность протокола

- Не угадывайте ФИО, должности, роли, адрес, дату, ответственных, сроки и результаты согласования.
- Приглашение подтверждает план, а не фактическое участие. Не отмечайте человека присутствующим только потому, что его пригласили.
- Предложение не равно решению; молчание не подтверждает согласие. Если решение не подтверждено, пишите «решение не зафиксировано».
- Каждое поручение — отдельная задача. Сохраняйте конкретное действие, результат, ответственного и срок, если они установлены. Пропуски отмечайте явно, не назначайте исполнителя по должности.
- Суммы, валюты, единицы измерения, ограничения и возражения переносите точно. Противоречащие версии укажите рядом и вынесите в открытые вопросы.
- «Не указано» означает отсутствие данных; «неразборчиво» — невозможность распознать запись; «требует уточнения» — неоднозначность; «не применимо» — поле не относится к встрече. «Не назначен» и «не установлен» используйте лишь при явном подтверждении.
- Не подставляйте текущую дату вместо даты встречи. Относительный срок переводите в дату только при однозначно известной точке отсчета; сохраняйте первоначальную формулировку.
- Для решений и поручений сохраняйте ссылку на источник и реальный таймкод либо номер абзаца. Не выдумывайте привязку.
- Служебные идентификаторы P-001, T-001, D-001, A-001, U-001 допустимы: это нумерация документа. При обновлении сохраняйте идентификаторы существующих записей.
- Автоматически подготовленный протокол — черновик до подтвержденного согласования. Не имитируйте подписи и не отправляйте документ участникам автоматически.

## Полная расшифровка

Приводите все реплики в исходной последовательности. Сохраняйте повторы, оговорки, слова-паразиты и незавершенные фразы. Добавлять пунктуацию для читаемости допустимо; превращать речь в литературный пересказ нельзя. Не применяйте стилистический редактор к дословному тексту.

Для каждой реплики указывайте говорящего, файл записи, таймкод начала/конца и текст. Если личность неизвестна, используйте устойчивые обозначения «Говорящий 1», «Говорящий 2». Не приписывайте голос конкретному участнику без подтверждения.

При одновременной речи сохраните все различимые реплики и отметьте перекрытие. События обозначайте только по записи: [неразборчиво, таймкод], [говорят одновременно], [пауза], [смех], [запись прервана], [фрагмент отсутствует]. Не додумывайте эмоции и мотивы.

Если таймкоды отсутствуют, пишите «таймкод не указан» и сохраняйте порядок реплик. Продолжительность файла и покрытие не выводите из количества слов. Даты и длительности не выдумывайте.

Перечислите все файлы в порядке воспроизведения, их длительности, обработанные интервалы и пропуски. Различайте полный охват доступной записи и наличие записи всей встречи. Если предоставлен фрагмент, прямо обозначьте это. Не скрывайте необработанный остаток за многоточием.

Если есть только заметки, составьте протокол по ним, а в части II укажите отсутствие исходной записи/расшифровки. Восстанавливать дословные реплики из краткого протокола нельзя.

## Перед выдачей

Проверьте имена, даты, ссылки между карточками, пропуски в поручениях, полноту расшифровки и статус согласования. Уберите инструкции для составителя из рабочего результата после заполнения, сохранив их в эталоне. Посмотрите, какие методические абзацы сохраняет программный заполнитель: это описано в filler-usage.md.

Пустая форма имеет плейсхолдеры намеренно; в заполненном документе каждое поле должно получить значение либо честную отметку об отсутствии данных.
