# Правила оформления протокола и расшифровки

Эталон — исправленный владельцем template.docx. Заполняйте его копию, сохраняя существующие стили, свойства абзацев и настройки страницы. Параметры ниже позволяют использовать форму без доступа к исходному проекту.

## Страница и шрифт

| Параметр | Значение |
|---|---|
| Бумага | A4, книжная ориентация |
| Поля сверху / снизу / слева / справа | 20 / 20 / 25 / 20 мм |
| Гарнитура всего документа | PT Serif |
| Основной текст | 12 пт, обычное начертание |
| Названия частей | 13 пт, полужирные, по центру |
| Названия разделов | 12 пт, полужирные, по центру |
| Межстрочный интервал | 1,15 |
| Основной абзац | По ширине, первая строка 1,25 см |
| Интервал после основного абзаца | 6 пт |
| Язык | Русский, ru-RU |
| Нумерация страниц | Поле PAGE снизу по центру; первая страница без номера |
| Цвет | Черный, без цветных заливок |

Шрифты Regular и Bold находятся в fonts/ вместе с лицензией. Они не внедрены в DOCX: установите их на машине просмотра, иначе редактор может подменить гарнитуру. Лицензию сохраняйте вместе со шрифтами.

Тело не выделять целиком полужирным. Не применять Arial, Calibri и другие гарнитуры, курсив, подчеркивание, цветные плашки и рамки абзацев. Иерархия строится на размере, полужирном начертании и отступах. Для полей ввода сохраняйте обычное оформление текста.

## Структура именно этой формы

Документ начинается с «ЧАСТЬ I. ПРОТОКОЛ ВСТРЕЧИ». Общий титул и вводный абзац удалены владельцем: не возвращайте их.

В части I восемь разделов: сведения, участники, повестка, решения, поручения, открытые вопросы, итоги/следующая встреча, материалы/согласование. Затем «ЧАСТЬ II. ПОЛНАЯ РАСШИФРОВКА ВСТРЕЧИ» с новой страницы и разделами 9–11.

При расширении карточек участника, решения или реплики копируйте исходные абзацы вместе с форматированием. Не сжимайте шрифт ради уменьшения числа страниц. Заголовок удерживайте со следующим абзацем; обозначение говорящего — с началом его реплики. Длинные реплики могут занимать несколько страниц.

## Поля и обозначения

В пустом шаблоне допустимы плейсхолдеры вида {{meeting_title}}. Во время автоматического заполнения не меняйте их имена вручную: они служат ключами данных. Квадратные скобки в расшифровке обозначают события записи: [неразборчиво], [смех], [запись прервана]. Это особенности данного документа.

В реквизитах даты — ДД.ММ.ГГГГ, время — ЧЧ:ММ с часовым поясом, таймкоды — ЧЧ:ММ:СС от начала указанного файла. Слова и написание дословной расшифровки не исправлять ради стилистических правил протокола.

## Проверка результата

Сверьте присутствие обеих частей, порядок реплик и сохранение всех доступных фрагментов. Проверьте переносы длинных полей, разрыв перед частью II, номера страниц и отсутствие одиноких заголовков. Окончательную пагинацию проверяйте в том редакторе, из которого будете печатать или экспортировать PDF: Word, LibreOffice и другие просмотрщики могут по-разному переносить строки.

Заполнитель сохраняет настройки исходного DOCX. Он не выполняет рендер, проверку юридической силы или проверку правильности распознавания речи.
