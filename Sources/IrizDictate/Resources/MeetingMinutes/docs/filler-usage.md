# Заполнитель протокола встречи

Скрипт работает локально на Python 3.10 и новее и не требует пакетов или сети.

```sh
python3 scripts/fill_template.py --data examples/data.example.json --output filled.docx
```

`--template` необязателен: по умолчанию используется `template.docx` рядом с папкой скрипта. `--data` — обязательный JSON, `--output` — новый путь. Существующий output и входные файлы не перезаписываются.

Формат JSON строго такой:

```json
{"fields": {"meeting_id": "..."}, "blocks": {"participants": [{"participant_id": "..."}]}}
```

`fields` содержит строковые значения общих полей. `blocks` содержит списки объектов с допустимыми полями соответствующего блока: `participants`, `topics`, `decisions`, `actions`, `open_issues`, `transcript_speakers`, `transcript_utterances`. Пропущенные значения получают `не указано`; `approval_status` по умолчанию — `черновик`. Пустой или не переданный блок получает одну строку `не зафиксировано в предоставленных данных`. Переносы строк в `utterance_text` сохраняются как переносы Word.

Неизвестные ключи и неверные типы отклоняются с ошибкой. Скрипт меняет только `word/document.xml`, сохраняя остальные части ZIP и свойства документа.

Полный перечень ключей находится в fields.json: поле group равно `fields` для общей шапки либо имени повторяемого блока. data.schema.json описывает ту же структуру для редакторов JSON. Поля повторяемых карточек передавайте внутри соответствующего списка blocks; помещать их в fields нельзя.

Заполнитель читает fields.json для контроля структуры template.docx. Вручную удаленное поле, повтор имени поля или измененные границы карточек останавливают заполнение. После изменения состава шаблона нужно согласованно обновить справочник и границы блоков скрипта.

Форматирование соседних фрагментов текста сохраняется, в том числе когда редактор Word разделил плейсхолдер между несколькими runs. Значения подставляются один раз: строка вида `{{meeting_id}}`, дословно произнесенная на встрече, останется в расшифровке, а не превратится в значение другого поля.

Методические абзацы шаблона («Карточка участника — повторить…», правила расшифровки и другие пояснения) заполнитель сохраняет. Перед выдачей рабочего протокола удалите ненужные пояснения в выходном файле, сохранив исходный template.docx. Скрипт не распознает аудио, не составляет протокол из речи и не проверяет содержание решений; он заполняет готовую форму подготовленными данными.
