**Result:** start with the newest version. Open its release notes for limits and verification details.

## 0.2.4

Model names and multilingual guides now match the app. The main README keeps Pantheon art; interface screenshots live in the walkthrough. Supported Whisper files use pinned downloads and SHA-256 verification. [Release notes](docs/releases/v0.2.4.md).

## 0.2.3 · 14 September 2026

Secure Keyboard Entry in another app no longer causes an immediate false refusal. Password fields and uncertain states still fail closed. [Release notes](docs/releases/v0.2.3.md).

## 0.2.2 · 13 September 2026

Meeting exports gained the built-in DOCX template, retained source material and explicit consent before agent processing. [Release notes](docs/releases/v0.2.2.md).

## 0.2.1 · 13 September 2026

The public DMG gained guided model installation, packaged translations, checksums and a build manifest. [Release notes](docs/releases/v0.2.1.md).

## 0.2.0 · 7 September 2026

First public release. [GitHub Release](https://github.com/zarubinvibe/iriz/releases/tag/v0.2.0).

Next: read the notes for the version you plan to install.
